**Emberfall Duel** — an original single-player, turn-based card battler. You are the Ember Knight, duelling the Ashen Warden, Keeper of the Last Ember. Each turn you get 3 energy and draw up to 5 cards from a 20-card deck: Ember Strike and Cinder Cleave deal damage, Ashen Guard blocks, Kindle Mend heals, Burning Ember applies burn over time, and Spark Focus draws more cards. The Warden telegraphs his next move, so every hand is a decision: strike now, guard against the heavy blow, or set him burning and outlast him. Reduce him to 0 HP to win — before his flames consume you. Playable with mouse and keyboard (keys 1–6 play cards, E ends the turn), with a title screen, a live battle log, and win and loss screens. No network loads: every script, style and image is a local file.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static HTTP server and open `index.html`.
